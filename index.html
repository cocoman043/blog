It's been one year since I quit my job! 🎉

2040 December 16

Hello! こんにちは！你好! 안녕! Musta mga paa! It's been one year since I quit teaching job and started working with wood! It hasn't been a great year for the province because of the on going war, but looking at the positive side, actually living my dream of making drawers is a wonderful experience. The last video I posted recieved a lot of comments asking me about my current setup and plans (thank you so much btw!), so here's an update blog post!

Figure 2. (left to right) Great tool chest, bought 3 of these. Wood storage I built. Home server for personal and family IT needs.

I've been trying to improve our garage since this is where I spend most of my time. I've bought 3 large tool chests but cleaning and organizing all of my stuff is still a chore :(.

First time working with this amount of wood meanth I had to build storage for it. I saw a reference for the plans online so I just copied it and adjusted it for the garage. Works perfectly.

For IT stuff, I'm still maintaining our home server we've had for the past decade. It stores the whole One Piece anime so we can stream it anytime, it also hosts this blog and other personal websites, and save backups of some important family documents and IDs. Planning on hosting more stuff like a mail server and expanding the storage soon.

Figure 3. Desk setup. Still using the Thinkpad from 2013.

For my desk, I just have this small table to put my Thinkpad on. I plan on asking my wife to 3D print some accesories for this to be more ergonomic since my back hurts sometimes when working here.

Figure 4. Reference photo for current project

Right now, I'm still working on this japanese style drawer that I'd like to finish before the next drone wave (hopefully we survive again). Mr. Tanaka told me that the next wave will be in a couple of weeks so I hope I have enough time.

Speaking of the war, I was inspired by the current events to go back into Game Development too! I've had this idea for a while now, but I never really had the time to work on it. But since ████████████████████, maybe I can actually do it now.

My wife and kids have been very supportive in the past year, and I'm really thankful for that. Through this harsh times, I've been trying to keep up to date with some of my friends from the MAHJONG club through the radio networks we built since college. Back then, we thought it was pretty cool to learn about radio and make our own stations but we didn't expect that this would be a necessity.

Figure 5. Currently rewatching Marineford Arc

Anyways, I'm still grinding on my walks, still trying to beat my personal best of 9.0 kph. I'm also rewatching The One Piece with the family. Our kids are finally understanding the essence of 仲間. And they're finally watching without subtitles! Teaching them Japanese has paid off.

Anyways, that's been it for my year! It's a new journey we're facing but I know we can push through this like always. Hopefully you guys are still safe out there.

Mabuhay ang Maharlika.

- RA
